# Иконка

`AppIcon.svg` — источник той иконки, что лежит в
`HabitFlow/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon.png`.
Пересобрать: `rsvg-convert -w 1024 -h 1024 AppIcon.svg -o ../../HabitFlow/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon.png`

Сетка 3×3 — это таблица активности из самого приложения, а не галочка в кружке,
которая есть у каждого трекера. Уровни заданы отдельными цветами, а не прозрачностью:
на тёмной подложке тусклые ячейки иначе пропадают, и на 29 пунктах сетка рассыпается.

Рядом лежат два отвергнутых варианта — кольцо, которое закрывает прилетевший сигнал,
и сегментированное кольцо. Оба читаются, но оба остались кольцом, как и старая иконка.
